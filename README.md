\# Rule-Based Chatbot



A simple chatbot built using Python and CustomTkinter.



\## Features



\- Modern GUI using CustomTkinter

\- Greetings and farewell responses

\- Date and time queries

\- Joke responses

\- Message timestamps

\- Auto-scrolling chat area



\## Technologies Used



\- Python

\- Tkinter

\- CustomTkinter



\## Installation



```bash

pip install -r requirements.txt

python main.py

```
